Make the cursor impossible to miss.

Autocuts records the real cursor, then redraws it. Size, color, and smoothing are all decisions you make after recording.

TL;DR

The cursor in an Autocuts recording is redrawn, not baked into the pixels. In the studio you can increase the cursor size for small screens, choose a color that matches your brand, and smooth the cursor path so movement reads as deliberate.

How to style the cursor

1

Increase the size

Pick a cursor size that stays readable when viewers watch on a phone or in a small embed.

2

Choose a color

Use the color picker to move away from the system look and match your product or brand.

3

Smooth the motion

Raise the smoothing slider to calm jittery travel; the cursor path stays true to where you actually worked.

Why redraw the cursor at all?

The macOS cursor was designed to be usable, not watchable. At tutorial size it is small, and raw mouse motion is noisy. Redrawing makes the pointer a first-class visual element you can style per export, without recording the take again.

Does the redrawn cursor stay accurate?

Yes. The cursor track follows the recorded positions; smoothing shapes the path between them. Clicks stay where you clicked, which keeps zooms and cursor motion in sync. See it with automatic zoom editing.
